# オハコ帳 セットアップ手順

自分専用のカラオケ記録アプリです。友達も同じURLで使えますが、データは一人ひとり別々に保存され、お互いに見えません。スマホのブラウザで開き、ホーム画面に追加するとアプリのように使えます。

## できること

| 機能 | 内容 |
|---|---|
| 曲リスト | 自分のアカウントだけに保存。友達とは別々のリストです |
| 点数メモ・お気に入り | 自分だけに保存されます(友達からは見えません) |
| 検索・並べ替え | 曲名・歌手名で検索、追加順・曲名・歌手名・自己ベスト・回数で並べ替え |
| YouTubeから追加 | 動画を検索して選ぶと、曲名・歌手名・動画がまとめて入る |
| 動画・サムネ | YouTubeを検索して登録、アプリ内で再生 |
| 歌詞 | Googleで歌詞を検索するボタン |
| 点数の修正 | 記録をタップして修正・削除 |
| 最後に歌った日 | 曲ごとに表示、「最近歌った順」「しばらく歌っていない順」で並べ替え |

全部で4ステップです。所要時間は30分ほど。費用はかかりません(どれも無料枠の範囲)。

---

## 0. まずお試し(設定なしで動きます)

`index.html` をパソコンのブラウザで開くと「お試しモード」で動きます。データはそのブラウザだけに保存され、例の曲が3つ入っています。

---

## 1. GitHub Pages で公開する

1. https://github.com でアカウントを作る(持っていれば不要)
2. 右上の「+」→「New repository」
   - Repository name:`ohako`(好きな名前でOK)
   - **Public** を選ぶ → 「Create repository」
3. 「uploading an existing file」のリンクを押し、このフォルダの**ファイルを全部**ドラッグ&ドロップ →「Commit changes」
4. リポジトリの「Settings」→ 左の「Pages」
   - Branch:`main` / `/(root)` を選んで「Save」
5. 1〜2分待つと、`https://あなたのユーザー名.github.io/ohako/` で開けるようになります

> 公開リポジトリなので `config.js` の中身は誰でも見られます。Firebaseのキーは見られても問題ない仕組みで、データはルール(手順2-6)で守られます。YouTubeのキーは手順3で「このサイトからしか使えない」ように制限します。

---

## 2. Firebase を設定する(ログインとデータ保存)

1. https://console.firebase.google.com を開き、Googleアカウントでログイン
2. 「プロジェクトを作成」→ 名前は `ohako` など → Googleアナリティクスは**オフ**でOK
3. プロジェクトのトップで **ウェブ(`</>`)** のアイコンを押す
   - アプリのニックネーム:`ohako` →「アプリを登録」
   - 表示された `firebaseConfig` の値(apiKey〜appId)を控える
4. 左メニュー「構築」→「**Authentication**」→「始める」
   - 「ログイン方法」タブで **Google** を有効にして保存
   - 「設定」タブ →「承認済みドメイン」→「ドメインの追加」で `あなたのユーザー名.github.io` を追加
5. 左メニュー「構築」→「**Firestore Database**」→「データベースの作成」
   - ロケーション:`asia-northeast1 (Tokyo)`
   - 「**本番環境モード**」で開始
6. Firestore の「**ルール**」タブを開き、中身を全部消して `firestore.rules` の内容を貼り付ける
   - `'your-address@gmail.com'` などを、**自分と友達のGoogleアカウントのメールアドレス**に書き換える(人数に合わせて行を増減)
   - 「公開」を押す

---

## 3. YouTube の APIキーを作る(アプリ内の動画検索)

1. https://console.cloud.google.com を開き、上部のプロジェクト選択で手順2で作った **Firebaseのプロジェクト** を選ぶ
2. 左メニュー「APIとサービス」→「ライブラリ」→「**YouTube Data API v3**」を検索 →「有効にする」
3. 「APIとサービス」→「認証情報」→「認証情報を作成」→「APIキー」
4. 作成されたキーの「キーを編集」で制限をかける
   - アプリケーションの制限:「**ウェブサイト**」→ `https://あなたのユーザー名.github.io/*` を追加
   - APIの制限:「キーを制限」→「YouTube Data API v3」だけにチェック
   - 保存
5. キーの文字列を控える

> 無料で使える量は1日あたり検索約100回です(友達全員の合計)。上限に達しても、動画URLの貼り付けでの登録はいつでも使えます。

---

## 4. config.js に書き込む

GitHubのリポジトリで `config.js` を開き、鉛筆アイコン(Edit)を押して書き換えます。

```js
firebase: {
  apiKey: "AIza....",          // 手順2-3で控えた値
  authDomain: "ohako-xxxx.firebaseapp.com",
  projectId: "ohako-xxxx",
  storageBucket: "ohako-xxxx.firebasestorage.app",
  messagingSenderId: "1234567890",
  appId: "1:1234567890:web:abcdef"
},
youtubeApiKey: "AIza....",     // 手順3で作ったキー
```

「Commit changes」で保存し、1〜2分後にページを開き直すと、Googleログイン画面が出ます。

---

## 友達に使ってもらう

1. 友達のメールアドレスを Firestore のルール(手順2-6)に追加して「公開」
2. URL(`https://あなたのユーザー名.github.io/ohako/`)を送る
3. スマホのホーム画面に追加してもらう
   - iPhone:Safariで開く → 共有ボタン →「ホーム画面に追加」
   - Android:Chromeで開く → 右上のメニュー →「ホーム画面に追加」

---

## 困ったとき

| 症状 | 対処 |
|---|---|
| ログインで「許可されていません」 | 手順2-4の「承認済みドメイン」に `○○.github.io` が入っているか確認 |
| ログインできたのに曲が出ない・保存できない | Firestoreのルールにそのアカウントのメールアドレスが入っているか確認 |
| 動画検索で「APIキーの制限」と出る | 手順3-4のウェブサイト制限のURLが、実際のページのURLと合っているか確認 |
| DAM・JOYSOUND・歌詞のボタンで検索結果が出ない | サイト側の仕様変更の可能性があります。`config.js` の `links` を書き換えれば直せます |

## ファイル構成

- `index.html` 画面の骨組み
- `style.css` 見た目
- `app.js` アプリ本体(データ保存・画面の動き・YouTube検索)
- `notes.js` 検索の文字そろえ、動画タイトルから曲名・歌手名を読み取る処理など
- `config.js` 設定(ここだけ書き換えればOK)
- `firestore.rules` データを守るルール(Firebaseに貼り付ける)
- `manifest.json`・`icon*` ホーム画面用のアイコン

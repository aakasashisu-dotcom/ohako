# オハコ帳

ログイン不要のカラオケ記録アプリです。URLを開けば誰でもすぐ使えます。スマホのブラウザで開き、ホーム画面に追加するとアプリのように使えます。

## できること

| 機能 | 内容 |
|---|---|
| 曲リスト | 曲の登録・編集・削除、曲名・歌手名で検索 |
| 並べ替え | 追加順・曲名・歌手名・自己ベスト・回数・最近歌った順・しばらく歌っていない順 |
| YouTubeから追加 | 動画を検索して選ぶと、曲名・歌手名・動画がまとめて入る |
| 動画・サムネ | アプリ内で再生、一覧にサムネ表示 |
| 歌詞 | Googleで歌詞を検索するボタン |
| 点数メモ | 点数・機種・キー・日付・メモを記録、タップで修正・削除 |
| 最後に歌った日 | 曲ごとに表示 |
| お気に入り | お気に入りの曲を自己ベスト順に一覧 |
| バックアップ | データをファイルに保存、別の端末で戻せる |

## データの保存について

- データは**使っている端末のブラウザの中だけ**に保存されます。サーバーには送られません。
- 別の端末とは共有されません。引っ越すときは、設定の「ファイルに保存」→ 新しい端末で「ファイルから戻す」。
- ブラウザのデータを消すと記録も消えます。ときどきバックアップしてください。
- iPhoneのSafariは、しばらく開かないサイトのデータを消すことがあります。**ホーム画面に追加して使う**と消えにくくなります。

## 公開の手順

### 1. GitHub Pages で公開する

1. GitHubで新しいリポジトリを作る(Public)
2. このフォルダのファイルを全部アップロードして「Commit changes」
3. 「Settings」→「Pages」→ Branch を `main` / `/(root)` にして「Save」
4. 数分後、`https://ユーザー名.github.io/リポジトリ名/` で開ける

### 2. YouTube の APIキーを作る(アプリ内の動画検索用)

1. https://console.cloud.google.com でプロジェクトを作る
2. 「APIとサービス」→「ライブラリ」→「YouTube Data API v3」を有効にする
3. 「認証情報」→「APIキー」を作成し、次の制限をかける
   - アプリケーションの制限:ウェブサイト → `https://ユーザー名.github.io/*`
   - APIの制限:YouTube Data API v3 のみ
4. `config.js` の `youtubeApiKey` にキーを書く

検索の上限は1日約100回で、**利用者全員の合計**です。上限に達した日は、動画URLの貼り付けで登録できます。

## 以前のログイン版のデータを移す

ログイン版で保存したデータは、`migrate.html`(`https://ユーザー名.github.io/ohako/migrate.html`)を開いてGoogleでログインすると、その端末に移せます。1回だけで大丈夫です。移したあと、別の端末にもほしい場合はバックアップファイルで移してください。

`config.js` の `firebase` の設定と `firestore.rules` は、この引っ越しにだけ使います。引っ越しが終われば不要です。

## 困ったとき

| 症状 | 対処 |
|---|---|
| 更新したのに画面が古い・真っ白 | 数分待ってから Ctrl + Shift + R で再読み込み |
| 動画検索で「上限に達しました」 | 翌日まで待つか、動画URLを貼り付けて登録 |
| 動画検索で「APIキーの制限」と出る | APIキーのウェブサイト制限のURLを確認 |
| 曲が保存されない | プライベートモード(シークレット)では保存できません。通常のモードで開いてください |

## ファイル構成

- `index.html` 画面の骨組み
- `style.css` 見た目
- `app.js` アプリ本体(データ保存・画面の動き・YouTube検索・バックアップ)
- `notes.js` 検索の文字そろえ、動画タイトルから曲名・歌手名を読み取る処理など
- `config.js` 設定(YouTubeのAPIキーなど)
- `migrate.html` ログイン版からのデータ引っ越し(1回だけ使う)
- `firestore.rules` ログイン版で使っていたルール(引っ越し後は不要)
- `manifest.json`・`icon*` ホーム画面用のアイコン
